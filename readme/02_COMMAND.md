# Command（コマンド）

よく使うコマンドは、[Makefile](../Makefile) にまとめています。`make <名前>` の形で実行します。

- [1. コンテナの操作](#1-コンテナの操作)
- [2. テストとコードの検査](#2-テストとコードの検査)
- [3. ライブラリの操作](#3-ライブラリの操作)
- [4. データベースの操作](#4-データベースの操作)
- [5. コンテナの中に入る](#5-コンテナの中に入る)

※ コマンドは、このリポジトリのフォルダの直下で実行してください。

※ 「起動中に使う」と書いたコマンドは、`make up` か `make upd` でコンテナを起動した状態で、別のターミナルから実行してください。

---

## 1. コンテナの操作

| コマンド | 内容 |
| --- | --- |
| `make setup` | 環境を作ります（ビルド、起動、データベースの準備）。初回だけ使います |
| `make up` | コンテナを起動します。記録がターミナルに出続けます。`Ctrl + C` で止まります |
| `make upd` | コンテナを、バックグラウンドで起動します。API の起動が終わるまで待ちます |
| `make stop` | コンテナを止めます |
| `make restart` | コンテナを再起動します |
| `make build` | コンテナをビルドし直します。`project.clj` か `Dockerfile` を変えたときに使います |
| `make ps` | コンテナの状態を表示します |
| `make down` | コンテナを削除します。データベースの中身は残ります |
| `make downv` | コンテナを、データベースの中身と、ダウンロードしたライブラリごと削除します。**データは消えます** |

`make stop` と `make down` の違いは、コンテナを残すかどうかです。ふだんは `make stop` で足ります。

## 2. テストとコードの検査

どれも、起動中に使います。

| コマンド | 内容 |
| --- | --- |
| `make clj/test` | テストを実行します |
| `make clj/check` | コードを検査します。規則（`clj/check-lint`）と書式（`clj/check-format`）の両方を見ます |
| `make clj/fix` | 書式を、自動で直します |

プルリクエストを作る前に、`make clj/fix`、`make clj/check`、`make clj/test` の順に実行してください。

規則の検査（clj-kondo）の指摘は、自動では直りません。表示されたファイル名と行番号を見て、手で直してください。

どのコマンドも、実行のたびに Java を起動するので、数秒から十数秒かかります。

## 3. ライブラリの操作

どれも、起動中に使います。

| コマンド | 内容 |
| --- | --- |
| `make clj/outdated` | 新しいバージョンが出ているライブラリを表示します |
| `make clj/install` | `project.clj` に書いたライブラリを、ダウンロードします |

ライブラリを足すときは、[project.clj](../project.clj) の `:dependencies` に、名前とバージョンを書き足します。そのあと、コンテナをビルドし直します。

```zsh
$ make build
$ make upd
```

ライブラリの名前とバージョンは、[Clojars](https://clojars.org/) か [Maven Central](https://central.sonatype.com/) で調べられます。

## 4. データベースの操作

どれも、起動中に使います。

| コマンド | 内容 |
| --- | --- |
| `make db/migrate` | データベースにつながることを確かめ、全テーブルを削除して、作り直します。**データは消えます** |
| `make db/reset` | `make db/migrate` と同じです |
| `make db/repl` | MySQL に接続して、SQL を入力できる状態にします。`exit` で抜けます |

テーブルを足したり変えたりしたときは、`make db/migrate` を実行してください。

データベースを見るソフトウェア（TablePlus など）からつなぐ場合は、次の設定を使います。

| 項目 | 値 |
| --- | --- |
| ホスト | `127.0.0.1` |
| ポート | `33306` |
| ユーザー | `root` |
| パスワード | （なし） |
| データベース | `demo` |

## 5. コンテナの中に入る

どれも、起動中に使います。

| コマンド | 内容 |
| --- | --- |
| `make clojure/login` | API のコンテナのシェルに入ります。`exit` で抜けます |
| `make clojure/repl` | Clojure の対話環境（REPL）を開きます。`exit` で抜けます |
| `make db/login` | データベースのコンテナのシェルに入ります。`exit` で抜けます |
